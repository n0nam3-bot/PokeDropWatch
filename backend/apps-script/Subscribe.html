HOW IT WORKS

Verified. Reviewed. In control.

Google Apps Script sends the code directly from the notification mailbox. This panel communicates with Apps Script itself; it does not use the website's cross-frame message bridge.

Your email is added to the private subscriber database only after the code is verified. New applications remain pending until the administrator approves them.

Codes expire after 10 minutes and can only be used once.
