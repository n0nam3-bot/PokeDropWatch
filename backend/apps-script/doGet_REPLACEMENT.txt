PokéDrop Watch Apps Script routing replacement

In the existing Apps Script project, replace the current doGet() function with
both functions below. Keep all other server functions, Script Properties,
HTML files (Index, Admin, Subscribe), and project settings unchanged.

This version opens Admin and Notify as top-level Apps Script pages, not as
cross-site iframes. It injects one shared PokéDrop Watch header and bottom nav
into the portal pages. The pages use google.script.run directly, so their
server calls remain inside the Apps Script origin.

function doGet(e) {
  const page = String(e && e.parameter && e.parameter.page || '').trim().toLowerCase();

  if (page === 'admin') {
    return pokedropPortalOutput_('Admin', 'PokéDrop Watch Admin', 'admin');
  }

  if (page === 'subscribe' || page === 'notify') {
    return pokedropPortalOutput_('Subscribe', 'PokéDrop Watch Email Alerts', 'notify');
  }

  const props = PropertiesService.getScriptProperties();
  const template = HtmlService.createTemplateFromFile('Index');
  template.siteOrigin = props.getProperty('SITE_ORIGIN') || 'https://n0nam3-bot.github.io';
  return template.evaluate().setTitle('PokéDrop Watch Verification');
}

After saving, deploy the existing web app as a New version. Keep its current
execution identity, access setting, Script Properties, and deployment URL.
Do not create a second deployment. The public site now opens the Apps Script
portal as a top-level page, so permissive cross-frame embedding is no longer needed.
