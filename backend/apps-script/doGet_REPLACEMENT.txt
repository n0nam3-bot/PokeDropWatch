Do not copy a doGet snippet or partial helper into Apps Script.

Use the complete file at backend/apps-script/Code.gs. In the Google Apps Script editor, open Code.gs, select all existing contents, and replace them with the complete contents of that file. It includes the existing verification, email, admin authentication, Firestore, and rate-limit functions plus the page routing and UI transformations.

Leave the existing Admin.html, Subscribe.html, and Index.html files in the Apps Script project in place. The new doGet(e) transforms the Admin and Subscribe HTML at render time, so the old hidden helper text and extra side panel are removed without copying partial HTML fragments.

Then save and deploy the existing web app as a New version. Keep the existing deployment URL, execute-as identity, and Anyone access setting.
