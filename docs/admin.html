How administrator tools work

Reviewing applications

Only applications with a verified email reach the subscriber list. New applications begin as Pending and do not receive alert emails until approved.

  • Approve changes a pending application to Active.
  • Reject closes a pending application without enabling alerts.
  • Suspend pauses an active subscription; Reactivate restores it.
  • Remove marks a record as removed from the notification list.

Subscriber preferences

Each record stores the product categories and retailer/source preferences selected during signup. Active subscribers receive only the alert types that match those preferences.

Security and session

Administrator sign-in and subscriber changes are handled by the private Apps Script backend. Browser code does not receive the Firestore service-account credentials. Administrator sessions expire after one hour.
