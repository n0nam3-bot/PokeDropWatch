PokéDrop Watch local display font

The stylesheet expects the PKMN RBYGSC font file at:
  docs/assets/fonts/PKMN-RBYGSC.ttf

Download it from https://www.dafont.com/pkmn-rbygsc.font, extract the ZIP, and upload the .ttf file here with the exact filename above. The DaFont URL is a download page, not a direct font file. The actual font file is not redistributed in this repository patch. Review the font author's license before publishing.

The pixel font is used for headings and interface labels. Long product names and descriptions intentionally use a readable system font.
