How email notifications work

1. Choose your preferences

Select the product categories and retailers or news sources you want to follow. These preferences are saved with your application.

2. Verify your email

Request a six-digit code and enter it in the form on this page. The code expires after 10 minutes and can only be used once. Verification confirms that you control the mailbox.

3. Wait for approval

After verification, the application is saved as Pending. An administrator must approve it before alert emails begin. Approved Active subscribers receive alerts matching their selected preferences.

Unsubscribing

Use the secure unsubscribe form and verify the mailbox with a one-time code before the subscription is marked unsubscribed.
